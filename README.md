# 🍏 Apple-Style 3D Website

An immersive **Apple-inspired 3D website** built with **React**, **Three.js**, **GSAP**, and **TailwindCSS**.  
Showcase products in **realistic 3D scenes** with **scroll-animated models**, **pinned sections**, and **fluid image transitions** — delivering a stunning, modern web experience.

---

![screenshort](/public/Home.png)

## 🚀 Overview

This project recreates the elegant, motion-driven aesthetic of Apple’s product pages — blending **3D visuals**, **scroll-based interactions**, and **smooth GSAP timelines** to produce an engaging storytelling experience.

---

## ⚙️ Tech Stack

### 🧠 **CodeRabbit**
An AI-powered code review assistant integrated into IDEs like **VS Code** and platforms like **GitHub** and **GitLab**.  
It provides:
- Context-aware feedback on pull requests
- Line-by-line code analysis
- Security vulnerability detection
- Code style and standard adherence
- Adaptive learning from team review patterns

### 🎬 **GSAP (GreenSock Animation Platform)**
Used for **dynamic, scroll-driven visuals**, featuring:
- `ScrollTrigger` for timeline-based scroll control
- `SplitText` for bold text reveals
- Pinned and parallax sections
- Scroll-synced video playback
- Image masking transitions
- Smooth multi-section animation timelines
- Custom animated carousel integration

### ⚛️ **React**
Provides the **declarative UI structure** and **component reusability**:
- Modular architecture for animation and layout
- Seamless GSAP integration
- Responsive state-driven carousel & video features

### 🎨 **Tailwind CSS**
Utility-first CSS framework ensuring **clean, responsive design**:
- Rapid UI prototyping with low-level utility classes
- Adaptive, pixel-perfect layouts across devices

### 🧩 **Three.js**
The backbone of the **3D rendering system**:
- WebGL-powered real-time 3D rendering
- Cameras, lights, and materials for realism
- Model importing and texture manipulation
- Scene graph management
- Animation & physics integration
- Post-processing and raycasting interactivity

### ⚡ **Vite**
A fast, modern **build tool and dev server**:
- Instant Hot Module Replacement (HMR)
- Lightning-fast startup
- Optimized production builds
- Perfect for animation-heavy workflows

### 🌐 **Zustand**
Lightweight **state management** for React:
- Minimal boilerplate global state
- Middleware support (logging, persistence)
- Reactive updates without re-renders
- Easy integration with components

## 🔋 Features

✅ **3D Product Scene with Realistic Lighting**  
Showcase products with cinematic lighting and lifelike shading.

✅ **Animate 3D Models on Scroll**  
Bind 3D animations directly to scroll position for full control.

✅ **ScrollTrigger Effects**  
GSAP-powered scroll-based animation control and syncing.

✅ **Pinned Sections**  
Lock sections in view while animating inner elements.

✅ **Image Masking Transitions**  
Dynamic scroll-triggered masking for eye-catching visuals.

✅ **Seamless Timeline Animations**  
Create multi-section transitions with buttery smooth flow.

✅ **Responsive Design**  
Optimized for all devices with adaptive layout and animation scaling.

✅ **Scalable Code Architecture**  
Reusable hooks, components, and stores for maintainable growth.
